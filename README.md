# Memory Game

Игра на запоминание карточек, реализованная в рамках задания Rolling Scopes School.

## Демо

- Деплой: [memory-game](https://yelantsevv.github.io/memory-game/)
- Задание: [RS School Memory Game](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game)

## Описание проекта

Игроку нужно открыть все пары карточек на игровом поле. В каждом ходе открываются две карты. Если символы совпадают, карты остаются открытыми и считаются найденной парой. Если символы разные, карты снова закрываются спустя короткую задержку.

В приложении реализованы:
- счётчик ходов,
- индикатор найденных пар,
- таблица лидеров,
- модальное окно победы после завершения игры.

## Функционал

- случайная генерация расположения карточек,
- игровое поле с адаптивной версткой,
- подсчёт ходов и прогресса игры,
- окно победы с итоговым результатом,
- сохранение результатов в `localStorage`,
- возможность начать новую игру,
- минималистичный и понятный пользовательский интерфейс.

## Запуск локально

1. Склонируйте репозиторий.
2. Откройте файл `index.html` через Live Server в VS Code 

## Правила игры

1. Нажмите на две карточки, чтобы открыть их.
2. Если символы совпадают, карточки остаются открытыми.
3. Если символы разные, они снова закрываются.
4. Необходимо открыть все пары за минимальное количество ходов.
